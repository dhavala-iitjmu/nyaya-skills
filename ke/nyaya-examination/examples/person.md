# Examine: synthetic Person example

## Input

> Examine this claim: two people with the same name must be the same person. Provide a counterexample and a reasoned judgment.

## Expected behavior

Identify the two named persons as pakṣa, their identity as sādhya, and equal names
as hetu. Even if name equality is established, the claimed connection (equal names
imply one person) is not established. A supplied case of different people sharing
a name defeats it; if none is supplied, label such a case as a hypothetical logical
counterexample rather than an observed fact. Ask for an identity criterion or
independent evidence. Reject this inference, while retaining uncertainty about
whether these particular persons are identical. Do not conclude they are distinct
merely because the proposed reason is bad. A full five-member exposition is optional.
